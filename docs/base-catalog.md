# Базовые справочники (черновик)

Поставляются с продуктом как системные. Компания может переименовать или
скрыть их, а также добавить свои типы этапов и события. Автомат фаз
при этом не меняется, см. [state-machine.md](state-machine.md). **Список
нужно сверить с практикой.**

Обозначения в колонке «Фаза»: **→ X** — событие ставит этапу фазу X;
**· X** — уточняющее событие, доступное в фазе X, фазу не меняет.

## Универсальные события (на любой точке)

| code | Название | Фаза |
|---|---|---|
| `arrived` | Прибыл | → arrived |
| `work_started` | Начато | → started |
| `paused` | Приостановлено | → paused ⟨причина⟩ |
| `resumed` | Возобновлено | → resumed |
| `work_finished` | Завершено | → completed |
| `departed` | Убыл | → departed |

Типы этапов ниже добавляют к ним свои формулировки и уточнения.

## Типы точек

Как выбрать тип и почему список такой короткий — см.
[reference.md](reference.md#как-выбрать-тип-точки).

| code | Название | Профиль | Убыть без работы |
|---|---|---|---|
| `depot` | База / гараж | point_simple | можно |
| `loading` | Погрузка | point_split | с причиной |
| `export_clearance` | Экспортное оформление | point_split | нельзя |
| `border_exit` | Выезд через погранпереход | point_single | нельзя |
| `border_entry` | Въезд через погранпереход | point_single | нельзя |
| `border_open` | Быстрый погранпереход (закрывается автоматически) | point_mark | — |
| `ferry_embark` | Заезд на паром | point_single | с причиной |
| `ferry_disembark` | Съезд с парома | point_simple | можно |
| `handover` | Сдача груза / прицепа / машины (транзита после нет) | point_split | с причиной |
| `takeover` | Приём груза / прицепа / машины | point_split | с причиной |
| `import_clearance` | Импортное оформление | point_split | нельзя |
| `unloading` | Выгрузка | point_split | с причиной |
| `waypoint` | Промежуточная точка | point_simple | можно |

Тип транзита один — `transit`. Вид: `road` (по умолчанию) или `ferry`
(между `ferry_embark` и `ferry_disembark`).

## События по типам точек

### Погрузка / выгрузка

| code | Название | Фаза | Поля |
|---|---|---|---|
| `queue_joined` | Встал в очередь | · arrived | номер в очереди |
| `at_dock` | Поставлен на рампу | · arrived | номер рампы |
| `loading_started` / `unloading_started` | Начало погрузки / выгрузки | → started | — |
| `photo_process` | Фото процесса | · started, paused, resumed, completed | фото |
| `loaded` / `unloaded` | Погружен / Выгружен | → completed | — |
| `seal_set` | Пломба установлена | · started, resumed, completed | номер, фото |
| `docs_received` | Документы получены | · completed | фото CMR/ТТН |
| `refused` | Отказ в погрузке / приёмке | · arrived, started, resumed | причина, фото |
| `claim` | Расхождение при выгрузке | · started, resumed, completed | описание, фото |

### Сдача / приём

Всегда пара: `handover`, затем `takeover`. Транзита между ними нет.
Принимает следующий водитель, он же ведёт рейс дальше.

| code | Название | Фаза | Поля |
|---|---|---|---|
| `queue_joined` / `at_dock` | Очередь / рампа | · arrived | — |
| `handover_started` | Начало сдачи | → started | — |
| `handed_over` | Сдано | → completed | что передано: груз / прицеп / тягач / контейнер / документы; кому |
| `takeover_started` | Начало приёма | → started | — |
| `taken_over` | Принято | → completed | что принято; замечания |
| `photo_process`, `seal_set`, `docs_received` | как на погрузке | | |

| `docs_submitted` | Подал документы | → started | фото |
| `inspection_started` / `inspection_finished` | Досмотр начат / окончен | · started, resumed | — |

### Погранпереходы

|---|---|---|---|

### Паром

| code | Название | Где | Фаза | Поля |

| `boarding` | Посадка | заезд | → started | — |

| `disembarked` | Съехал | съезд | → arrived (транзит-паром завершается) | — |

## Незапланированное — события, а не точки

Доступны на любом текущем этапе (точке или транзите).

| code | Название | Поля |
|---|---|---|
| `inspection` | Контроль: фито / вет / сан / полиция | вид, фото, комментарий |
| `weighing` | Взвешивание | вес, фото |
| `crew_change` | Смена водителя | новый водитель, комментарий |
| `trailer_dropped` | Отцепил прицеп | номер прицепа, фото |
| `trailer_coupled` | Прицепил прицеп | номер прицепа, фото |

## События транзита

| code | Название | Вид | Фаза | Поля |
|---|---|---|---|---|
| — | (старт) | любой | → started | автоматически при «Убыл» / «На борту» с предыдущей точки |
| `rest_started` | Начал отдых | дорога | → paused | тип: короткий / ежедневный / еженедельный |
| `stopped` | Остановка | дорога | → paused | причина: пробка, полиция, погода, дорога закрыта, прочее |
| `moving_resumed` | Продолжил движение | дорога | → resumed | — |
| `fuel_receipt` | Заправка | дорога | · started, paused, resumed | литры, сумма, фото чека |
| `ferry_departed` | Отплытие | паром | · started | — |
| `ferry_delayed` | Задержка парома | паром | · started | новое время |
| `eta_update` | Новое ETA | любой | · started, paused, resumed | время, причина |
| `expense` | Расход (дорога, стоянка, паром) | любой | · started, paused, resumed | сумма, валюта, фото |
| — | (финиш) | любой | → completed | автоматически при «Прибыл» / «Съехал» на следующей точке |

## Общие уточняющие события

| code | Название | Фаза | Поля |

## Требования к фазам (по умолчанию)

Подробно механика описана в [events-and-requirements.md](events-and-requirements.md).

| Где | Требование | До фазы | Вид | Строгость |
|---|---|---|---|---|
| Погрузка | Фото процесса погрузки, ≥ 3, только камера, с «Начато» | Убыл | photo | block |
| Погрузка | Фото груза в кузове перед закрытием | Убыл | photo | block |
| Погрузка | Номер пломбы (скан или ввод) + фото пломбы | Убыл | scan + photo | block |
| Погрузка | Подписанная CMR / ТТН | Убыл | document | block |
| Выгрузка | Фото груза до начала выгрузки | Начато | photo | warn |
| Выгрузка | Фото процесса выгрузки, ≥ 3, с «Начато» | Убыл | photo | block |
| Выгрузка | Подпись получателя или фото подписанной CMR | Убыл | signature / document | block |
| Оформление | Фото документов о выпуске | Убыл | document | block |
| Сдача / приём | Фото груза / прицепа при передаче, ≥ 4, с «Начато» | Завершено | photo | block |
| Сдача / приём | Акт приёма-передачи | Убыл | document | block |
| Заезд на паром | Фото билета / брони | Начато (посадка) | photo | warn |
| тег `#reefer` | Температура + фото дисплея рефа | Убыл (погрузка) | number + photo | block |
| тег `#food` | Фото чистого пустого кузова | Начато (погрузка) | photo | block |
| тег `#adr` | «Опасный груз: не останавливаться у жилых домов и АЗС» | Прибыл (погрузка) | acknowledgement | block |
| тег `#reefer` | «Проверьте, что реф включён и выставлена температура» | Начато (погрузка) | acknowledgement | block |
| тег `#adr` | Фото табличек ADR | Убыл (погрузка) | photo | block |
| тег `#high_value` | Фото пломбы на каждой точке | Убыл (любая точка) | photo | block |

## Системные события

| code | Когда |
|---|---|
| `late_for_window` | у точки нет фазы `arrived` к `window_to` |
| `eta_after_window` | ETA позже окна прибытия |
| `long_wait` | в фазе `arrived` дольше N минут (очередь, простой) |
| `long_stop` | транзит в фазе `paused` дольше N минут без отдыха |
| `no_signal` | от водителя нет данных N часов |
| `event_conflict` | событие не вписалось в автомат при пересчёте |
