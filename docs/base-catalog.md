# Базовые справочники (черновик)

Поставляются с продуктом как системные. Компания может переименовать или
скрыть их, а также добавить свои. **Список нужно сверить с практикой.**

## Типы этапов

| code | Название |
|---|---|
| `loading` | Погрузка |
| `unloading` | Выгрузка |
| `customs_export` | Таможня (экспорт) |
| `customs_import` | Таможня (импорт) |
| `border` | Пересечение границы |
| `parking` | Стоянка / отдых |
| `fuel` | Заправка |
| `waypoint` | Промежуточная точка |

## Требования к этапу

| code | Тип | Пример |
|---|---|---|
| `photo_cargo` | photo | Фото груза в кузове |
| `photo_seal` | photo | Фото пломбы с номером |
| `signed_cmr` | document | Подписанная CMR / ТТН |
| `temp_reading` | number | Температура в рефе |
| `pallets_count` | number | Количество паллет |
| `seal_number` | text | Номер пломбы |
| `checklist` | checkbox | Отметка «груз закреплён» и т.п. |

## События водителя

| code | Название | Применимо | Поля | Эффект |
|---|---|---|---|---|
| `trip_accepted` | Рейс принят | рейс | — | trip_start |
| `arrived` | Прибыл на точку | любой этап | — | stage_start |
| `queue` | Стою в очереди | любой этап | комментарий | — |
| `loading_started` | Начало погрузки | погрузка | — | — |
| `loaded` | Погружен | погрузка | фото, пломба | — |
| `unloading_started` | Начало выгрузки | выгрузка | — | — |
| `unloaded` | Выгружен | выгрузка | фото, документы | — |
| `customs_in` | Подал документы на таможню | таможня | фото | — |
| `customs_out` | Таможня пройдена | таможня | — | — |
| `departed` | Убыл с точки | любой этап | — | stage_complete |
| `delay` | Задержка | рейс / этап | причина, ETA, комментарий | — (warning) |
| `breakdown` | Поломка | рейс | фото, комментарий | — (critical) |
| `accident` | ДТП | рейс | фото, комментарий | — (critical) |
| `cargo_damage` | Повреждение / недостача груза | рейс / этап | фото, комментарий | — (critical) |
| `rest` | Начало отдыха | рейс | — | — |
| `rest_end` | Окончание отдыха | рейс | — | — |
| `trip_finished` | Рейс завершён | рейс | — | trip_complete |

## События диспетчера

| code | Название | Применимо | Поля |
|---|---|---|---|
| `route_changed` | Изменение маршрута | рейс | комментарий |
| `docs_sent` | Документы отправлены водителю | рейс / этап | файлы |
| `customer_notified` | Клиент уведомлён | рейс / этап | комментарий |
| `slot_confirmed` | Слот на складе подтверждён | этап | время, номер слота |
| `downtime_confirmed` | Простой подтверждён | этап | часы, комментарий |
| `stage_closed_manually` | Этап закрыт вручную | этап | причина |
| `trip_closed` | Рейс закрыт (документы получены) | рейс | — |
| `trip_cancelled` | Рейс отменён | рейс | причина |
