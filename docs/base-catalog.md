# Базовые события

Чистый справочник событий Plobi. Каждое событие ставит этапу одну фазу или уточняет его. Внешняя система
сама сопоставляет свои пункты с этими событиями, автомат Plobi принимает их или нет. Правила автомата —
[overview.md](overview.md), модель этапов и фаз — [reference.md](reference.md).

Названия, что видит клиент и автопубликацию ведут на вкладке «Типы событий». Набор событий меняется скриптом
базы.

## События

| code | Название | Где | Фаза | Клиент видит |
|---|---|---|---|---|
| `arrived` | Прибыл | любая точка: ближайшая впереди, где прибытия ещё не было | прибыл | только фаза |
| `departed` | Убыл | любая точка, кроме погранпереходов: текущая | убыл | только фаза |
| `loading_started` | Начали загружать | погрузка | начато | только фаза |
| `loaded` | Загружен, ожидаю документы | погрузка | завершено | сразу |
| `documents_received` | Документы получил | погрузка | — | сразу |
| `export_clearance_started` | Начали оформление | затаможка | начато | только фаза |
| `export_cleared` | Затаможен | затаможка | завершено | сразу |
| `border_control_started` | Начат пограничный контроль | выезд, въезд | начато | только фаза |
| `border_crossed` | Пересёк границу | ближайший неотмеченный пост: выезд, въезд, быстрый переход | убыл | сразу |
| `import_clearance_started` | Начали оформление | растаможка | начато | только фаза |
| `import_cleared` | Растаможен | растаможка | завершено | сразу |
| `unloading_started` | Начали выгружать | выгрузка | начато | сразу |
| `unloaded` | Выгружен | выгрузка | завершено | сразу |
| `handover_started` | Начал сдачу | сдача | начато | только фаза |
| `handed_over` | Сдал груз | сдача | завершено | только фаза |
| `takeover_started` | Начал приём | приём | начато | только фаза |
| `taken_over` | Принял груз | приём | завершено | только фаза |
| `in_transit` | В пути | транзит; особое — «сердцебиение»: единственное, которое можно повторять | начато | только фаза |
| `cancelled` | Отмена события | системное: создаёт Plobi, на любом этапе | — | сразу |

## Остановка и продолжение

Причина остановки — само событие. Каждое ставит этапу фазу «Приостановлено»; клиент и менеджер видят причину за
фазой: «Приостановлено [Ремонт]». Продолжение одно на все причины. Все остановки и «Продолжил» — решает менеджер,
без автопубликации.

| code | Название | Где | Вина по умолчанию |
|---|---|---|---|
| `downtime` | Простой — причина не из списка, с комментарием | любой этап | — |
| `rest` | Отдых | только транзит | — |
| `repair` | Ремонт | только транзит | перевозчик |
| `traffic_ban` | Запрет движения | только транзит | внешняя |
| `bad_weather` | Непогода | только транзит | внешняя |
| `inspection` | Досмотр | только транзит | внешняя |
| `accident` | ДТП | только транзит | — |
| `resumed` | Продолжил | любой этап | |

- **Пауза — посреди работы или движения.** Пока этап ждёт начала работы или отъезда («Прибыл», «Завершено»),
  остановка остаётся уточнением: это ожидание автомат считает сам.
- **Конец паузы:** «Продолжил», «В пути» на транзите или любая следующая фаза («Завершено», прибытие дальше).
- **Вторая остановка во время паузы** новую паузу не открывает, но меняет причину.
- **Остановка транзита до начала движения** (отдых сразу после погрузки) сначала ставит транзиту «Начато».
- **ДТП** — событие-остановка. Разбор происшествия (инцидент) — отдельный процесс, который оно запустит; пока его нет.
- **Вина** (заказчик, перевозчик, внешняя, ничья) — у самой остановки. Окончательно её определяет менеджер в
  своём кабинете, после согласования с клиентом; водитель вину не выбирает. Пока менеджер не решил, вина
  предварительная (со знаком вопроса): из внешней системы или по умолчанию типа события. После решения менеджера
  внешняя система её не меняет. Простой заказчика — это «Простой» с виной «заказчик», отдельного события нет.
  Клиент вину не видит. Нужна для отчётов по простоям.

Общие «Начато» (`work_started`) и «Завершено» (`work_finished`) заведены без типов этапов — в настройках в строке
«Не привязаны к этапам». Привязывают их к этапам без своей формулировки.

Фазы без событий:
- **Убыл с точки** закрывается и сам: следующим прибытием или фазой дальше по маршруту.
- **Завершено у транзита** ставится прибытием на следующую точку.

## На будущее — вместе с приложением водителя

Из целевой модели, пока не заведено:
- уточнения на точке: очередь, рампа, фото процесса, пломба, отказ в погрузке или приёмке, расхождение;
- оформление: подал документы, досмотр, задержан и задержание снято (свои формулировки паузы);
- паром: регистрация, посадка, на борту, съехал; события транзита-парома;
- транзит: заправка, новое ETA, расходы;
- незапланированное на любом этапе: контроль, взвешивание, смена водителя, отцепил или прицепил прицеп;
- требования к фазам, инциденты, события диспетчера.
