# Этапы, состояния и фазы — справочник

Короткое и точное описание трёх основных понятий. Подробная механика — в
[state-machine.md](state-machine.md), полный перечень событий — в
[base-catalog.md](base-catalog.md).

> То, что раньше называли «статусом этапа», в системе называется
> **состоянием**. Слово «статус» в модели не используется.

## Коротко

| Понятие | Отвечает на вопрос | Значения |
|---|---|---|
| **Этап** | из чего состоит рейс? | точки и транзиты по порядку |
| **Состояние** этапа | где этап в рейсе? | впереди, в процессе, пройден, пропущен |
| **Фаза** этапа | что на этапе произошло последним? | прибыл, начато, приостановлено, возобновлено, завершено, убыл |

Ни состояние, ни фазу **нельзя выставить руками**. Водитель и диспетчер
отмечают **события**, а система вычисляет из них фазу, а из фазы —
состояние.

---

## 1. Этап

Рейс — это последовательность этапов двух видов, которые чередуются:

```
[Точка] → (Транзит) → [Точка] → (Транзит) → [Точка]
```

| Вид | Что это | Пример |
|---|---|---|
| **Точка** (`point`) | место, где что-то происходит | погрузка, таможня, порт, выгрузка |
| **Транзит** (`transit`) | движение между двумя точками | дорога, паром, поезд |

- Внешняя система присылает **только точки**, а транзиты между ними сервер
  вставляет сам.
- В каждый момент у рейса **ровно один** этап в состоянии «в процессе».
- У каждого этапа есть **тип**, а у каждого типа — **профиль**, то есть
  набор фаз, через которые он проходит (см. раздел 3).

### Типы точек

| Код | Название | Профиль |
|---|---|---|
| `loading` | Погрузка | полный |
| `unloading` | Выгрузка | полный |
| `customs_export` | Экспортная таможня | полный |
| `customs_import` | Импортная таможня | полный |
| `customs_transit_open` | Открытие транзита (T1/TIR) | полный |
| `customs_transit_close` | Закрытие транзита | полный |
| `control` | Фито / вет / санконтроль | полный |
| `border` | Пересечение границы | без «Завершено» |
| `weighing` | Взвешивание | без «Завершено» |
| `ferry_port_departure` | Порт отправления (паром) | без «Завершено» |
| `rail_terminal_departure` | Ж/д терминал отправления | без «Завершено» |
| `rail_terminal_arrival` | Ж/д терминал прибытия | без «Завершено» |
| `trailer_drop` | Отцепка прицепа | без «Завершено» |
| `trailer_pickup` | Сцепка прицепа | без «Завершено» |
| `crew_change` | Смена водителя | без «Завершено» |
| `ferry_port_arrival` | Порт прибытия (паром) | простой |
| `parking` | Плановая стоянка | простой |
| `fuel` | Плановая заправка | простой |
| `waypoint` | Промежуточная точка | простой |

### Типы транзитов

| Код | Название | Когда вставляется |
|---|---|---|
| `transit_road` | Дорога | между любыми двумя точками |
| `transit_ferry` | Паром | между портом отправления и портом прибытия |
| `transit_rail` | Поезд (контрейлер) | между ж/д терминалами |

Компания может добавлять свои типы этапов. Новый тип выбирает один из
профилей, и автомат для него писать не нужно.

## 2. Состояние этапа

Где этап находится в рейсе.

| Состояние | Название | Когда |
|---|---|---|
| `ahead` | Впереди | по этапу ещё не было событий |
| `in_progress` | В процессе | у этапа есть фаза, но она ещё не финальная |
| `passed` | Пройден | этап дошёл до финальной фазы своего профиля |
| `skipped` | Пропущен | диспетчер пропустил этап |

### Переходы

```
Впереди ──► В процессе ──► Пройден
   │             │             │
   └─────────────┴─────────────┴──► Пропущен
```

- **Впереди → В процессе → Пройден** — только вперёд и только по порядку.
  Вернуться назад нельзя.
- **Пропущен** — из любого состояния. Ставит только диспетчер и только с
  причиной.
- **Порядок этапов:** этап может перейти в «В процессе», только если все
  предыдущие этапы пройдены или пропущены.

### Состояние рейса

| Состояние | Когда |
|---|---|
| `draft` — Черновик | водитель не назначен |
| `assigned` — Назначен | водитель назначен |
| `accepted` — Принят | водитель принял рейс |
| `in_progress` — В процессе | первый этап начался |
| `finished` — Выполнен | все этапы пройдены или пропущены |
| `closed` — Закрыт | диспетчер закрыл рейс (документы получены) |
| `cancelled` — Отменён | рейс отменён с причиной |

## 3. Фаза этапа

Последняя **веха** этапа, то есть момент, который уже произошёл. Каждая фаза
названа по событию и имеет отметку времени.

| Фаза | Название | Что означает | Точка | Транзит |
|---|---|---|---|---|
| `arrived` | Прибыл | исполнитель на месте, работа не начата | ✔ | — |
| `started` | Начато | основное действие этапа началось | ✔ | ✔ (тронулся) |
| `paused` | Приостановлено | действие прервано | ✔ | ✔ (остановка) |
| `resumed` | Возобновлено | действие продолжено после паузы | ✔ | ✔ |
| `completed` | Завершено | основное действие этапа закончено | ✔ | ✔ (финальная) |
| `departed` | Убыл | исполнитель покинул точку | ✔ (финальная) | — |

Главное различие:

- **«Завершено»** относится к **работе**. После него машина ещё стоит на
  точке: ждёт документы, пломбу, выпуск.
- **«Убыл»** относится к **месту**: машина уехала с точки.

У транзита места нет, поэтому «Прибыл» и «Убыл» к нему не применяются.
Транзит начинается в момент «Убыл» с предыдущей точки и завершается в
момент «Прибыл» на следующую.

### Профили — какие фазы есть у этапа

Автомат фаз один для всех этапов. Профиль только выбирает из него нужные
фазы.

| Профиль | Цепочка фаз | Для чего |
|---|---|---|
| **Полный** (`point_split`) | Прибыл → Начато ⇄ Приостановлено / Возобновлено → Завершено → Убыл | погрузка, выгрузка, таможня: видно ожидание после работы |
| **Без «Завершено»** (`point_single`) | Прибыл → Начато ⇄ Приостановлено / Возобновлено → Убыл | граница, порт, сцепка: конец работы совпадает с убытием |
| **Простой** (`point_simple`) | Прибыл → Убыл | заправка, стоянка, промежуточная точка |
| **Транзит** (`transit`) | Начато ⇄ Приостановлено / Возобновлено → Завершено | любой транзит |

### Переходы между фазами (полный профиль)

```
(нет фазы) ─► Прибыл ─► Начато ─► Завершено ─► Убыл
                 │         │  ▲
                 │         ▼  │
                 │   Приостановлено ⇄ Возобновлено ─► Завершено
                 │
                 └──► Убыл   только если тип этапа разрешает «убыть без работы»
```

- Приостановить можно только из «Начато» или «Возобновлено».
- После «Приостановлено» сначала нужно «Возобновлено», а уже потом
  «Завершено».
- **«Убыл» без работы** сразу после «Прибыл» зависит от типа этапа:
  - на погрузке и выгрузке — с обязательной причиной;
  - на таможне и границе — нельзя;
  - на заправке и стоянке — свободно.
  
  Требования к работе в этом случае получают отметку «неприменимо».

### Связь фазы и состояния

| Фаза | Состояние |
|---|---|
| нет фазы | Впереди |
| любая, кроме финальной | В процессе |
| финальная (`departed` у точки, `completed` у транзита) | Пройден |

## 4. Границы этапов

Одно действие водителя закрывает один этап и открывает следующий:

| Действие | Текущий этап | Следующий этап |
|---|---|---|
| **Убыл** с точки | фаза «Убыл», состояние «Пройден» | транзит: фаза «Начато», состояние «В процессе» |
| **Прибыл** на точку | транзит: фаза «Завершено», состояние «Пройден» | точка: фаза «Прибыл», состояние «В процессе» |

Для парома: «На борту» в порту отправления — это «Убыл», а «Съехал с
парома» в порту прибытия — это «Прибыл».

## 5. События

Событие — то, что отмечает пользователь. Есть два вида:

- **События фазы** ставят фазу. У каждого типа этапа свои формулировки, но
  под ними общие фазы:

  | Тип этапа | → Начато | → Приостановлено | → Возобновлено | → Завершено | → Убыл |
  |---|---|---|---|---|---|
  | Погрузка | Начало погрузки | Пауза | Продолжить | Погружен | Убыл |
  | Выгрузка | Начало выгрузки | Пауза | Продолжить | Выгружен | Убыл |
  | Таможня | Подал документы | Задержан | Задержание снято | Выпуск | Убыл |
  | Граница | Начат контроль | — | — | — | Границу пересёк |
  | Порт отправления | Посадка | — | — | — | На борту |
  | Дорога (транзит) | *(Убыл с пред. точки)* | Отдых / Остановка | Продолжил движение | *(Прибыл на след. точку)* | — |

  На любой точке есть и **универсальные** события: «Прибыл», «Начато»,
  «Приостановлено», «Возобновлено», «Завершено», «Убыл».

- **Уточняющие события** фазу не меняют, а добавляют подробности. Например:
  «Встал в очередь», «Поставлен на рампу», «Фото процесса», «Пломба
  установлена», «Документы получены», «Новое ETA», «Ознакомлен».

Кроме того, есть **инциденты** (поломка, ДТП, повреждение груза). Они идут
параллельно фазам: могут поставить этап на паузу и запретить «Убыл», пока
диспетчер их не решит.

## 6. Время, которое считается само

Точка:

```
Прибыл ─ ожидание ─ Начато ─ работа (без пауз) ─ Завершено ─ ожидание убытия ─ Убыл
```

Транзит:

```
Начато ─ в пути (без пауз: отдых, пробка, полиция) ─ Завершено
```

Из этих отметок получаются:

- простой до начала работы;
- чистое время работы;
- простой после работы (документы, выпуск);
- время в пути;
- время отдыха и вынужденных стоянок.
