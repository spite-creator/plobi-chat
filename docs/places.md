# Места

**Место** — склад, таможенный пост, порт, стоянка. Это постоянная сущность,
а этап рейса на неё **ссылается**: адрес, координаты, часовой пояс и
контакты вводятся один раз и подтягиваются в каждый рейс.

```
Place
  id, external_id, name
  kind?                    склад / таможня / порт / граница / стоянка ...
  address, lat, lon, timezone
  working_hours?           часы работы, перерывы
  contacts[]               { name, phone, role }
  tags[]
```

- Интеграции присылают ссылку на место по `external_id` и не дублируют
  адрес.
- Этап может ссылаться на место или содержать адрес напрямую, если место
  разовое. Адрес из места можно уточнить в этапе.
- Позже: отчёты по местам (средний простой на складе, выполнение окон).

Всё, что водитель должен знать и сделать на точке («позвони Ашоту», «не
грузить выше 2 ярусов»), кладётся **в этап** как требования, см.
[events-and-requirements.md](events-and-requirements.md#3-требования-этапа).
К месту требования не привязываются.
