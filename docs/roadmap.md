# План работ

## Этап 0. Каркас
- Монорепозиторий: `server/` (Fastify, Drizzle), `web/` (React PWA), `docker/`.
- `docker-compose.yml`: app, postgres; автоматические миграции.
- Пользователи, вход, роли; первый админ создаётся при первом запуске.
- API-клиент PWA сразу со списком зеркал и переключением между ними.
- Общий пакет `shared/` с автоматом этапов (сервер и PWA).
- OpenAPI и Swagger UI.

## Этап 1. MVP: рейсы и события
- Справочники с базовым набором и их редактирование в админке.
- Создание рейса с этапами и требованиями: через API и в интерфейсе.
- Экран водителя: список рейсов, карточка рейса, кнопки событий по этапу,
  формы по схеме полей, фото с камеры.
- Экран диспетчера: список рейсов, таймлайн событий, свои события.
- Офлайн-очередь событий.

## Этап 2. Мессенджер
- Личные, групповые и рейсовые чаты, WebSocket.
- Файлы, голосовые сообщения, статус «прочитано».
- Карточки рейса и событий в ленте чата.
- Web Push.

## Этап 3. Интеграции и поставка
- Токены интеграций со scopes, upsert по `external_id`, `act_as`.
- Вебхуки с подписью и повторами.
- Приём позиций с GPS-трекеров, карта рейса.
- Лицензионный ключ, лимит пользователей.
- Документация для администратора клиента: установка, обновление, бэкап.

## Потом
- SSO (OIDC / Keycloak / AD), мультиязычность интерфейса (ru, en, …).
- Справочник ТС и прицепов, шаблоны рейсов.
- Отчёты: простои, опоздания, выполнение окон.
- Нативная оболочка (Capacitor) для фонового GPS, если понадобится.
