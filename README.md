# Plobi Chat

Мессенджер для логистических компаний: чат между диспетчерами и водителями
плюс модуль рейсов с этапами, требованиями и событиями.

## Принципы продукта

1. **Self-hosted.** Продаётся как Docker-образ. Каждая компания разворачивает
   его у себя, и все данные остаются на её серверах. Разработчик продукта не
   хранит и не видит данные клиентов.
2. **API-first.** Всё, что можно сделать в интерфейсе, можно сделать через API:
   загрузить рейсы, создать пользователей и чаты, отправить сообщение,
   выставить событие. Встроенного маршрутизатора нет: маршрут приходит готовым
   из внешней системы (TMS, 1С, ERP) или создаётся вручную.
3. **PWA.** Одно веб-приложение для водителя и диспетчера. Его можно
   установить на телефон и пользоваться без магазинов приложений.
4. **Настраиваемость.** Есть базовый набор типов этапов и событий. Компания
   может добавлять свои, причём у каждой роли свой перечень событий.
5. **Без географических ограничений.** Мультиязычность, часовые пояса, время в
   UTC, международные документы.
